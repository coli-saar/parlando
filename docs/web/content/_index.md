<section class="home-principles" aria-label="Parlando principles">
  <article>
    <p class="principle-number">01</p>
    <h2>Define the task</h2>
    <p>A game states what each role can observe, which actions are legal, and what counts as completion.</p>
  </article>
  <article>
    <p class="principle-number">02</p>
    <h2>Control the condition</h2>
    <p>An experiment records recruitment, pairing, timing, agents, communication, and consent as one versioned condition.</p>
  </article>
  <article>
    <p class="principle-number">03</p>
    <h2>Preserve the evidence</h2>
    <p>Every session remains connected to the game version and experimental revision that explain its record.</p>
  </article>
</section>
