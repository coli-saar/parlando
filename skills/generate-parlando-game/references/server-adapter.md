# Rust game implementation

Start with the crate generated by `parlando new my-game --lang rust`. Its library implements `parlando_game_sdk::Game` and exports the Wasm interface. Use the generated Beacon Relay game and its scenarios as executable examples of typed configuration, actions, borrowed views, and rejection handling.

Keep private state in the session object. Implement `init` from the supplied configuration and seed. In `step`, check every precondition before modifying state or consuming randomness. Compute each player's complete view with `view_a` and `view_b`. Completion is visible to both seats. Include separate private facts in the corresponding final view.

The SDK supplies the schema and binary encoding. Optional checkpoints must contain enough information to restore deterministic behavior, including random generator state. Exercise recovery against the compiled component with `parlando test`.

Use the standard host for deployment. A custom Rust process is useful when registering an in-process policy. In that case, load the same component with `LoadedGame::load` and pass it to `Server::new`.
